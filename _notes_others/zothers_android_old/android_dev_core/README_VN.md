# Tìm hiểu các Khái niệm Android (Learn Android Concepts)

Mã nguồn ví dụ để tìm hiểu các khái niệm khác nhau liên quan đến Phát triển Ứng dụng Android.

Tham khảo trang web - Udacity, Udemy, Google Samples, CodePath Android Cliff Notes

## 1. Phát triển Ứng dụng (App Development)

### Giao diện Người dùng và Đầu vào (User Interfaces and Inputs)

- #### Ứng dụng Đố vui (Quiz App)

  Views, Layouts, Đầu vào người dùng (User Inputs)

- #### Ứng dụng Thẻ lên máy bay (Boarding Pass App)

  Constraint Layout, Data Binding, Khả năng tiếp cận (Accessibility)

- #### Ứng dụng Trau chuốt Giao diện (Visual Polish App)

  Màu sắc và phông chữ, Styles và themes, Bố cục đáp ứng (Responsive Layout), Bộ chọn cảm ứng (Touch Selectors)

### Điều hướng (Navigation)

- #### Ứng dụng Học tiếng Miwok (Miwok Language App)

  Fragments, Swipe Views with Tab, ViewPager, FragmentPagerAdapter, Trình phát phương tiện (Media Player)
  
- #### Ứng dụng Hướng dẫn Du lịch (Tour Guide App)

  Fragments, Swipe Views with Tab, ViewPager, FragmentPagerAdapter
  
- #### Ứng dụng Âm nhạc (Music App)

  Fragments, Swipe Views with Tab, ViewPager, FragmentPagerAdapter, Trình phát phương tiện (Media Player)

- #### Ứng dụng Android Me (Android Me App)

  Fragments, Master/Detail Flow, Thiết kế đáp ứng (Responsive Design)

### Lập trình Mạng (Networking)

- #### Ứng dụng Theo dõi Động đất Trực tiếp (Live Earthquake App)

  Asynctask Loader, JSON Parsing, HTTP Requesting, RESTful API - sử dụng USGS API
  
- #### Ứng dụng Tìm sách (Book Listing App)

  Asynctask Loader, JSON Parsing, HTTP Requesting, RESTful API - sử dụng Google Books API
  
- #### Ứng dụng Đọc tin tức (News App)

  Asynctask Loader, JSON Parsing, HTTP Requesting, RESTful API - sử dụng The Guardian API

### Cơ sở Dữ liệu (Database)

- #### Ứng dụng Xếp hàng Nhà hàng (Restaurant Queuing App)

  Lưu trữ dữ liệu trong SQLite
  
- #### Ứng dụng Thuật ngữ Droid Ví dụ (Droid Terms Example App)

  SQLite, Asynctask, Content Providers, Cursors
  
- #### Ứng dụng Danh sách Việc cần làm (To-do List App)

  SQLite, CRUD, Xây dựng Content Providers, URI Matcher, Cursor Loader

- #### Ứng dụng Trạm cứu hộ Thú cưng (Pet Shelter App)

  SQLite, Content Provider, DBHelper, Cursor Adapter, Cursor Loader
  
- #### Ứng dụng Quản lý Kho hàng (Inventory App)

  SQLite, Content Provider, DBHelper, Cursor Adapter, Cursor Loader
  
- #### Ứng dụng Theo dõi Thói quen (Habit Tracker App)

  SQLite, Content Provider, DBHelper, Cursor Adapter, Cursor Loader

### Thông báo & Công cụ tiện ích (Notification & Widgets)

- #### Ứng dụng Nhắc nhở Uống nước (Hydration Reminder App)

  Notification, Firebase Job Dispatcher

- #### Ứng dụng Khu vườn của Tôi (My Garden App)

  App Widgets
  
### Các API của Google (Google APIs)

- #### Ứng dụng Nhận diện Biểu cảm (Emojify Me App)

  Play Services - Nhận diện khuôn mặt với Mobile Vision (Mobile Vision Face Recognition)

- #### Ứng dụng Squawker (Squawker App)

  Firebase Cloud Messaging (FCM), Firebase Notifications
