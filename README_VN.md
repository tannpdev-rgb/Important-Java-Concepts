## [2023] Phát triển Android (Java & Các thư viện Android) [Đang hoàn thiện]
![android libraries](https://github.com/Suryakant-Bharti/Important-Java-Concepts/assets/2780145/da6e7738-1920-4fc0-b147-705c5c4b6c3e)

### GHI CHÚ [Thông tin hữu ích] :

*[-> Retrofit](_notes_others/android_retrofit/README_VN.md) - HTTP client an toàn về kiểu dữ liệu (type-safe) cho Java & Android*

*[-> Glide](_notes_others/android_glide/README_VN.md) - thư viện tải hình ảnh hiệu quả với khả năng giải mã media, cache trên bộ nhớ và ổ đĩa*

*[-> RoomDB](_notes_others/android_roomdb/README_VN.md) - Trình bao bọc SQLite dựa trên ORM giúp truy cập cơ sở dữ liệu một cách trôi chảy (fluent)*

*[-> WorkManager](_notes_others/android_workmanager/README_VN.md) - lên lịch cho các tác vụ bất đồng bộ, có thể hoãn lại (deferrable)*

*-> ViewModel - lưu trữ & quản lý dữ liệu liên quan đến UI theo cách nhận biết vòng đời (lifecycle-aware)*

*-> LiveData - trình giữ dữ liệu có thể quan sát (observable) nhận biết vòng đời, hỗ trợ data binding sẵn có (ootb)*

*-> DataBinding - liên kết các thành phần UI với nguồn dữ liệu theo cách khai báo (declarative)*

*-> RxJava - lập trình bất đồng bộ, dựa trên sự kiện sử dụng các chuỗi observable*

*-> Dagger - framework Dependency Injection tĩnh, biên dịch trước (compile-time)*

*-> JUnit - kiểm thử ở phía nhà phát triển trên JVM (framework unit testing)*

*-> Mockito - tạo các đối tượng giả (mocking) trong unit test (framework test doubling)*
